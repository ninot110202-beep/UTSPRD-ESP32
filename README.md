## Monitoring Kondisi Motor Industri Berbasis IoT

Proyek ini merupakan sistem monitoring kondisi motor industri berbasis **Internet of Things (IoT)** yang dirancang untuk memantau performa mesin secara **real-time** guna mencegah kerusakan fatal melalui deteksi dini. Sistem menggunakan **ESP32** sebagai mikrokontroler utama dengan konsumsi daya rendah, dilengkapi fitur keamanan hardware **ATECC608B** untuk enkripsi data dan autentikasi perangkat.

Perangkat dirancang dengan standar proteksi **IP65**, sehingga tahan terhadap debu dan air serta cocok digunakan di lingkungan industri yang ekstrem. Sistem bekerja dengan metode **threshold-based monitoring**, yaitu memberikan alarm otomatis ketika parameter mesin melewati batas aman.

### Keunggulan Proyek

* **Monitoring real-time** kondisi motor industri
* **Peringatan dini otomatis** untuk mencegah kerusakan mesin
* **Keamanan data tinggi** dengan hardware encryption
* **Hemat energi** menggunakan ESP32 low-power
* **Mengurangi limbah industri** melalui maintenance berbasis kondisi
* **Biaya implementasi terjangkau** (±Rp270.000)

### Tujuan

Meningkatkan efisiensi operasional industri, memperpanjang umur mesin, serta mendukung konsep **Smart Factory** yang aman, hemat energi, dan berkelanjutan.
